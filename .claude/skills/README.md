Copiées telles quelles depuis ces dépôts (aucun script exécuté à l'installation).
Pour les mettre à jour, recopier le dossier `skills/<nom>` du dépôt d'origine.

**memory-bank** : tient la mémoire du projet dans un fichier de brief à la racine. Dans ce dépôt, ce
fichier est **`BRIEF.md`** (majuscules, déjà présent sur `main`) : le skill dit `brief.md`, mais il ne faut
**pas** créer un second fichier ; mettre à jour `BRIEF.md`. Le brief de ce dépôt a plus de 5 sections (carte du
dépôt, règles de travail, pièges) : conserver cette structure plus riche, qui contient les cinq sections du
skill (aperçu, stack, architecture et pièges, roadmap, journal).
